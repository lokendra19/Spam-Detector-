
An AI-based Email Spam Detection web application that classifies emails as Spam or Ham using machine learning and rule-based techniques.

## Features
- Email spam classification using ML models
- Rule-based keyword detection
- Spam explanation with confidence score
- Login and signup authentication
- Phishing and suspicious content detection
- User scan history dashboard

## Tech Stack
- Python
- Flask / Streamlit
- Machine Learning (Scikit-learn, NLP)
- HTML, CSS
- JSON / CSV for data storage
